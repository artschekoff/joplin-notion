## 😤 Проблема

Вы любите Joplin — опенсорс, приватность, скорость. Но Markdown-редактор мешает, когда просто хочется **думать и писать**:

- 🔤 Постоянно отвлекаешься на синтаксис Markdown прямо в процессе мысли
- 📋 Чтобы переставить блок — вырезать, промотать, вставить. Снова и снова
- 📄 Поделиться заметкой как PDF или Word-документом — только через внешние инструменты
- ⌨️ Мышь замедляет. Клавиатурным маньякам здесь неуютно
- 🔄 Отредактировал заметку в основном редакторе — блочный редактор показывает старую версию

Notion нравится. Блочный редактор там удобный. Но отдавать свои заметки в облако не хочется.

**А что если можно получить и то, и другое?**

## 🚀 Возможности

### 🧱 Блочное редактирование

Каждый абзац, заголовок, список и таблица — это **отдельный блок**, который можно перетащить. Переставляйте структуру заметки drag-and-drop'ом — забудьте про вырезание и вставку.

| Тип блока | Аналог в Markdown |
|---|---|
| 📝 Параграф | обычный текст |
| 📌 Заголовок (H1–H3) | `# ## ###` |
| 📋 Маркированный список | `- пункт` |
| 🔢 Нумерованный список | `1. пункт` |
| ✅ Чеклист | `- [ ] / - [x]` |
| 💻 Блок кода | ` ```код``` ` |
| 💬 Цитата | `> текст` |
| 📊 Таблица | `\| кол \| кол \|` |
| ➖ Разделитель | `---` |

Все блоки **конвертируются в чистый Markdown** и обратно — заметки остаются полностью совместимы с Joplin.

---

### ⌨️ Встроенный Vim-режим

Для тех, кто не хочет тянуться к мышке. Нажмите `Esc` — и вы в **Normal mode**:

| Клавиша | Действие |
|---|---|
| `j` / `k` | Перейти к следующему / предыдущему блоку |
| `gg` / `G` | Перейти к первому / последнему блоку |
| `i` / `a` | Войти в Insert mode (начало / конец) |
| `o` / `O` | Новый блок снизу / сверху |
| `dd` | Удалить текущий блок |
| `yy` | Скопировать (yank) текущий блок |
| `p` / `P` | Вставить блок ниже / выше |
| `u` | Отменить действие |
| `Esc` | Вернуться в Normal mode |

> Собственный стек undo. `Ctrl+Z` / `Cmd+Z` тоже работают в Insert mode.

---

### 📚 Оглавление

Плавающая панель **Outline** автоматически строится из заголовков заметки. Клик по пункту — мгновенная прокрутка к нужному разделу. Scroll-spy подсвечивает текущий раздел при прокрутке.

Переключается кнопкой **[TOC]** — предпочтение сохраняется между сессиями.

---

### 📤 Экспорт и отправка одним кликом

Хватит копировать текст в Google Docs только для того, чтобы отправить PDF.

| Действие | Как работает |
|---|---|
| 📧 Отправить по email | Открывает почтовый клиент с темой и текстом заметки |
| 📄 Экспорт в PDF | Встроенный PDF-принт Joplin — запускается из тулбара |
| 📝 Экспорт в DOCX | Pandoc конвертирует заметку в формат Word |
| 📃 Экспорт в RTF | Pandoc конвертирует в Rich Text Format |

---

### 🤖 Интеграция с AI

Выделите любой текст или откройте меню блока (⋮⋮) и **отправьте его прямо в AI-чат**. Работает совместно с плагином-компаньоном для ИИ — никакого копирования.

---

### 🔄 Всегда актуальный контент

Отредактировал заметку в основном редакторе Joplin, синхронизировал с другого устройства, обновил через другой плагин — блочный редактор **автоматически подгружает последнюю версию**. Никаких устаревших данных.

## 📦 Установка

### Из магазина плагинов Joplin *(скоро)*

1. Откройте Joplin → **Инструменты → Настройки → Плагины**
2. Найдите `Notion Block Editor`
3. Нажмите **Установить** → Перезапустите Joplin

### Ручная установка

```bash
# 1. Клонируем репозиторий
git clone https://github.com/riskyworks/joplin-notion.git
cd joplin-notion

# 2. Устанавливаем зависимости
npm install

# 3. Собираем плагин
npm run dist
```

Затем в Joplin: **Инструменты → Настройки → Плагины → Установить из файла** → выберите `publish/net.roxl.joplin-notion.jpl`

## 🎮 Использование

### Открыть блочный редактор

| Способ | Действие |
|---|---|
| ⌨️ Горячая клавиша | `Ctrl+Shift+B` (Windows/Linux) / `Cmd+Shift+B` (macOS) |
| 🖱️ Тулбар | Кнопка **⊞** на панели инструментов заметки |
| 📋 Меню | **Инструменты → Toggle Block Editor** |

Панель открывается рядом со списком заметок. Повторное нажатие скрывает её.

### Переключение заметок

Просто кликните на другую заметку в боковой панели — блочный редактор загрузит её мгновенно.

### Форматирование текста

Выделите текст внутри любого блока — появится тулбар:

`Жирный` · `Курсив` · `Ссылка` · `Ask AI`

### Меню блока

Наведите на блок и нажмите **⋮⋮** (или начните вводить `/` в пустом блоке), чтобы сменить тип блока или вызвать дополнительные действия.

## ⚙️ Требования

- **Joplin** ≥ 1.6
- **Node.js** ≥ 16 (только при сборке из исходников)
- **Pandoc** (опционально — нужен только для экспорта в DOCX / RTF)

---

## 🧩 Интеграция с другими плагинами

Плагин публикует два публичных настройки, которые другие плагины могут читать:

| Ключ | Тип | Описание |
|---|---|---|
| `notion.blockEditor.active` | `boolean` | `true` когда панель блочного редактора открыта |
| `notion.askAI.request` | `string` | JSON `{text, ts}` — пишется при нажатии Ask AI |

## 📋 История версий

### v0.1.1 — 25 апреля 2025 *(текущая)*

**Исправления**

- 🔄 **Блочный редактор теперь синхронизируется при внешних изменениях заметки.** Раньше, если заметку редактировали в основном редакторе Joplin, синхронизировали с другого устройства или изменял другой плагин — панель продолжала показывать старый текст. Добавлен обработчик `onNoteChange`, который автоматически перезагружает редактор.
- 🛡️ Добавлена защита от петли сохранения (`isSavingFromPanel`) — редактор больше не перезагружает сам себя после собственного debounce-сохранения, что исключало бы мерцание контента во время печати.

---

### v0.1.0 — 24 апреля 2025 *(первый релиз)*

**Ключевые возможности**

- 🧱 Блочный редактор на базе [Editor.js](https://editorjs.io) — параграфы, заголовки (H1–H3), списки, чеклисты, код, цитаты, таблицы, разделители
- 🖱️ Drag-and-drop перестановка блоков
- ↔️ Двусторонняя конвертация Markdown ↔ блоки — полная совместимость с форматом Joplin
- 📌 Инлайн-форматирование: жирный, курсив, код, ссылки, зачёркивание
- ⌨️ Vim Normal mode: навигация, yank/paste, вставка, удаление, собственный стек undo
- 📚 Панель оглавления со scroll-spy
- 📊 Редактируемые таблицы с contenteditable-ячейками
- 📤 Экспорт: email с текстом, PDF, DOCX (pandoc), RTF (pandoc)
- 🤖 Ask AI — инлайн-инструмент и тюн блока для отправки текста в AI-плагин
- 🔖 Шина настроек для межплагинного взаимодействия (`notion.blockEditor.active`, `notion.askAI.request`)
- ⌨️ Горячая клавиша `Ctrl/Cmd+Shift+B` для переключения панели
- 🔍 Поиск по типам блоков в поповере, навигация Tab, подтверждение Enter
